# Жизненный цикл помощи

Помощь проходит последовательные статусы `ACCEPTED` → `COMPLETED` →
`CONFIRMED`. Монеты и успешная статистика начисляются только при переходе в
`CONFIRMED`; блокировка строки помощи и идемпотентные кошелёчные операции
обеспечивают однократное начисление.

Получатель или администратор может подтвердить `COMPLETED` вручную. Если
получатель не подтвердил помощь в течение 168 часов с момента `completed_at`,
планировщик автоматически переводит её в `CONFIRMED`. Автоподтверждение
записывается в историю с ролью `SYSTEM`, сохраняет статус заявки `COMPLETED`,
начисляет обычные награды и отправляет уведомления помощнику и получателю.
Порог задаётся параметром `app.help.completed-timeout-hours`
(`HELP_COMPLETED_TIMEOUT_HOURS`, по умолчанию 168); автоматический переход
можно отключить через `app.help.auto-confirm-enabled`
(`HELP_AUTO_CONFIRM_ENABLED`).

Активная блокировка получателя не отменяет награду помощнику: ручное
администраторское и системное подтверждения продолжают работать. При этом
`JwtAuthFilter` не изменялся: заблокированный пользователь может быть не
допущен к самостоятельному вызову ручного подтверждения. Автоматическое
подтверждение по сроку служит fallback; остаётся открытым вопрос, следует ли
отдельно разрешить этот self-service маршрут в фильтре.
